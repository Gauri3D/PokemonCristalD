# PokemonCristalD · Gauri.3D

Página de bienvenida para cartucho NFC de Pokémon Cristal con EmulatorJS (`gbc`).

## Archivo del juego

El sitio espera un archivo autorizado para distribución llamado exactamente `PokemonCristal.gbc` en la raíz del repositorio, junto a `index.html`. La ROM no está incluida en este commit.

## Publicación

En **Settings → Pages → Build and deployment**, selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**. La URL será https://gauri3d.github.io/PokemonCristalD/ .

El botón INICIAR JUEGO prepara EmulatorJS; después se usa el control de inicio del propio emulador. Comprueba la apertura por NFC en Safari, los controles táctiles y el guardado en un dispositivo real.
